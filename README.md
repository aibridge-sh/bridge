# AI Bridge

**Bridge** is a macOS app for running AI coding agents — Claude Code, Codex,
Grok, OpenCode and more — side by side, with your terminals, clusters,
databases and SSH hosts in one window. Learn more at
[aibridge.sh](https://aibridge.sh).

Bridge is **closed source**. This repository holds:

- **[Releases](../../releases)** — the signed, notarized app. Bridge updates
  itself from here.
- **[Issues](../../issues)** — bug reports and ideas, in public.

## Report a bug or suggest a feature

The easiest way is from inside Bridge: **Settings › Send feedback**, or
**Help › Report a Bug** / **Help › Suggest a Feature**. Bridge helps you
write it up, adds your versions if you want, shows you exactly what will be
posted, and posts it from your GitHub account — or opens it here in your
browser.

You can also open an issue here directly. Before you do, please search the
[existing issues](../../issues): if yours is there, a 👍 on it helps more
than a duplicate.

Issues are public and stay public. Leave out anything private: tokens,
customer names, internal hostnames.

## Something private?

- **A security problem** — please report it privately: see
  [SECURITY.md](SECURITY.md). Never as a public issue.
- **Your licence, a payment or your account** — email
  [support@aibridge.sh](mailto:support@aibridge.sh).
