# Security

Bridge runs AI agents with access to your terminals, repositories, clusters
and databases, so we take reports seriously and want to hear about anything
that could put a user at risk.

## Reporting a vulnerability

**Please do not open a public issue.** Report it privately, either:

- through GitHub's **[private vulnerability reporting](../../security/advisories/new)**
  for this repository, or
- by email to **security@aibridge.sh**.

Tell us what you found, the Bridge version (Help › Copy Diagnostics lists
it), and how to reproduce it. We'll acknowledge your
report, keep you updated while we fix it, and credit you in the release notes
if you'd like.

## Supported versions

Security fixes ship in the latest release. Bridge updates itself; to check by
hand, choose **Check for Updates** from Bridge's icon in the menu bar.
